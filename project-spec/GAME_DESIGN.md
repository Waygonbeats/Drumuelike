# Game Design

## Genre
- Action Roguelike
- Rhythm
- Top-down / isometric

---

## Core Loop
1. Игрок входит в комнату.
2. Появляются враги.
3. Игрок выбирает цель (target).
4. Начинается ритмический бой.
5. Игрок воспроизводит паттерн.
6. Враг получает урон.
7. Комната очищается.

---

## Core Mechanic
Enemy = Rhythm Pattern.

Примеры:
- Slime → LL
- Bat → LR
- Knight → RLR

Игрок должен повторить последовательность ударов.

---

## Combat Flow
1. Игрок выбирает врага.
2. Активируется паттерн врага.
3. Паттерн отображается в RhythmLine.
4. Игрок воспроизводит его.
5. Во время боя:
   - игрок может двигаться
   - остальные враги атакуют обычным образом
6. Результат:
   - Success → урон врагу
   - Fail → сброс комбо, атака игрока

---

## Damage Model
- У врагов есть HP.
- Каждый удар в паттерне наносит урон:
  - Perfect → высокий урон
  - Good → средний урон
  - Miss → нет урона и сброс streak
- Урон применяется на каждый hit внутри паттерна.
- Непрерывные успешные удары (streak) увеличивают Multiplier.

---

## Rhythm Streak System
Multiplier зависит от непрерывности ритма:
- Каждый успешный hit увеличивает streak.
- Good не ломает цепочку.
- Miss сбрасывает streak и multiplier.
- Multiplier = 1 + (streak / N), целочисленно.
- Multiplier увеличивает урон и ускоряет бой.

---

## Player Skill Expression
- Играть безопасно (Good) → бой дольше.
- Играть идеально (Perfect + streak) → быстрее убивать, контролировать бой.

---

## Enemy Interaction
- Во время ритм-боя активен только 1 паттерн.
- Остальные враги:
  - двигаются
  - создают давление
  - атакуют, но не требуют ритм-попаданий.

---

## UI
- Паттерн отображается над врагом и переносится в верхнюю часть экрана при активации.
- Показывается текущий и следующий input.
- Multiplier и streak отображаются для фидбека.

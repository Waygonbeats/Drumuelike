# Rhythm Roguelike

## Core Idea
Enemy = rhythm pattern.

Игрок сражается с врагами, воспроизводя ритмические паттерны под BPM. Чем точнее игрок попадает в ритм, тем быстрее и эффективнее проходит бой.

## Key Design
- Каждый враг имеет ритм.
- Игрок наносит урон, попадая в такт.
- Непрерывная серия правильных ударов увеличивает Multiplier и ускоряет бой.

## Stack
- Engine: Godot
- Language: C#

## Goal (MVP)
Проверить:
- ощущение ритма
- удовольствие от попаданий (Perfect)
- связку: ритм + уклонение
